# Dependencias del proyecto

Listado de las dependencias declaradas en `package.json`. Las versiones indicadas son los rangos configurados en el proyecto.

## Aplicación móvil

| Dependencia | Versión | Función |
|---|---:|---|
| `expo` | `^58.0.0` | Plataforma para desarrollar y ejecutar la app con React Native. |
| `react` | `19.3.0` | Biblioteca para construir interfaces mediante componentes. |
| `react-native` | `0.88.1` | Permite crear la aplicación móvil para Android e iOS. |
| `@expo/vector-icons` | `^15.0.2` | Conjunto de iconos listo para usar en Expo. |
| `@react-native-vector-icons/material-icons` | `^13.1.2` | Iconos de Material Design para React Native. |
| `@react-navigation/native` | `^7.3.16` | Base para gestionar la navegación de la aplicación. |
| `@react-navigation/bottom-tabs` | `^7.18.16` | Navegación con pestañas en la parte inferior. |
| `@react-navigation/native-stack` | `^7.18.8` | Navegación tipo pila entre pantallas. |
| `@react-native-async-storage/async-storage` | `^2.2.0` | Almacenamiento persistente de datos simples en el dispositivo. |
| `@rneui/base` | `^5.0.0` | Componentes y utilidades base de React Native Elements. |
| `@rneui/themed` | `^5.0.0` | Componentes de interfaz con soporte de temas y estilos. |
| `expo-constants` | `~58.0.14` | Acceso a información de configuración y del entorno de Expo. |
| `expo-font` | `~58.0.11` | Carga de fuentes personalizadas. |
| `expo-image-picker` | `~58.0.10` | Selección de imágenes desde la galería o la cámara. |
| `expo-splash-screen` | `~58.0.12` | Control de la pantalla de inicio mientras carga la app. |
| `expo-status-bar` | `~58.0.4` | Configuración de la barra de estado del dispositivo. |
| `react-native-calendars` | `^1.1314.0` | Componentes de calendario para React Native. |
| `react-native-safe-area-context` | `~5.10.1` | Adaptación del diseño a las zonas seguras de la pantalla. |
| `react-native-screens` | `~4.30.1` | Integración de pantallas nativas para la navegación. |

## Backend

| Dependencia | Versión | Función |
|---|---:|---|
| `express` | `^5.2.1` | Framework para crear el servidor y las rutas de la API. |
| `cookie-parser` | `^1.4.7` | Lee y procesa cookies recibidas en solicitudes HTTP. |
| `jsonwebtoken` | `^9.0.3` | Genera y valida tokens JWT para autenticación. |
| `multer` | `^2.2.0` | Gestiona la recepción de archivos subidos al servidor. |

## Desarrollo

| Dependencia | Versión | Función |
|---|---:|---|
| `nodemon` | `^3.1.14` | Reinicia automáticamente el servidor cuando cambian sus archivos. |

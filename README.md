# Para ejecutar:

```
1. Clonar el repositorio
2. cd joditas
2. npm install --legacy-peer-deps //instala dependencias
3. npx nodemon backend/server.js //levanta el backend (correr en una terminal)
4. npm start //inicia expo version 58 (correr en una terminal distinta)
5. escanear el qr y disfrutar
```

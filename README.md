## Para ejecutar:

```
1. Clonar el repositorio
2. cd joditas
2. npm install --legacy-peer-deps //instala dependencias
3. npx nodemon backend/server.js //levanta el backend (correr en una terminal)
4. npm start //inicia expo version 58 (correr en una terminal distinta)
5. escanear el qr y disfrutar
```
## Casos de uso:

> Un posible caso de uso sería un usuario administrador, el cual ingresa a la aplicación, navega a la solapa de "Login", ingresa las credenciales apropiadas (user = jere, pass = 1234, super seguro por suerte) y una vez iniciada su sesión ya tiene la posibilidad de crear un evento nuevo.

> Otro caso de uso sería un usuario no-admin, el cual ingresa a la aplicación, navega a la solapa de "Calendar" y busca una fiesta para un fin de semana donde quiere salir. Una vez encontrado el evento, puede seleccionarlo y verificar los datos de este para ver si es de su interés.
